Сначала посмотри, как это выглядит

Открой отдельную ознакомительную версию. Можно создать профиль в этом браузере, выбрать урок и пройти занятие.

Открыть тренажёр →

Эта версия хранит прогресс только в текущем браузере. Для постоянных занятий и входа с другого устройства опубликуй полный проект.

1. Загрузи полный проект на GitHub

  1. Создай репозиторий на GitHub, например wordberry-english. Можно выбрать Private.
  2. Через Add file → Upload files загрузи файлы и папки из распакованного проекта. Сохрани вложенность. ZIP как один файл не подходит.
  3. На первой странице репозитория должны лежать package.json, package-lock.json, netlify.toml. В netlify/functions — wordbook.mjs.
  4. Нажми Commit changes.

Проверь, что в репозитории видны папки scripts, src, data, shared, server и netlify. Открой scripts: там должен быть build.mjs. Если загрузились только отдельные файлы без папок, Netlify не сможет собрать приложение. Файл wordbook.mjs должен лежать в netlify/functions.

2. Импортируй репозиторий в Netlify

  1. Войди в Netlify.
  2. Создай проект: Add new project / Import an existing project → GitHub.
  3. Выбери репозиторий Wordberry и проверь настройки ниже.
  4. Запусти deploy и дождись успешной публикации.

Серверная часть и хранилище используют возможности Netlify. Отдельный ключ ИИ и отдельная внешняя база не нужны; использование сервисов зависит от условий аккаунта Netlify.

3. Проверь регистрацию

Открой опубликованный адрес в новом браузере. Должны быть вкладки «Войти» / «Создать профиль».

Если показывается только поле имени с предупреждением «только в текущем браузере», серверная часть недоступна. Проверь успешность deploy и наличие функции wordbook. Одна папка dist или один HTML не включают облачную регистрацию.

4. Сделай профиль дочери

  1. Имя или псевдоним, уникальный логин и пароль от 8 символов.
  2. Сохрани код восстановления у взрослого.
  3. Открой «Мои уроки» и выбери тему, которую проходите в школе.
  4. Начни с 3–5 слов в режиме «Все 4 навыка».

Не нужно проходить всё с первого урока. Например, тема школьных предметов — сразу 1a.

5. Проверь память и звук

  1. Ответь на несколько карточек и дождись надписи «Прогресс сохранён».
  2. Закрой и открой страницу: должны сохраниться имя и следующая карточка.
  3. На другом устройстве войди с тем же логином и паролем: прогресс должен совпасть.
  4. В карточке проверь обычное и замедленное произношение.

Голоса и запись микрофона зависят от браузера и устройства. Реальные облачные сервисы проверяются после публикации.

Как добавить школьные слова

«Мои уроки» → «Добавить свой урок». Название и строки вида:

apple | яблоко | I eat an apple. | Я ем яблоко.

В примере слово должно быть целиком и в той же форме. Для apple подходит an apple, но не pineapple. Все четыре тренировки создадутся автоматически.

Что считается выученным

Освоено: есть верный ответ без подсказки в переводе, написании, аудировании и предложении.

Закреплено: по два верных ответа подряд в каждом навыке и успешное повторение спустя минимум 20 часов после первой встречи.

Слова с ошибками возвращаются в тренировку. История ответов остаётся.
