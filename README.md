# Wordberry — английский по школьным урокам

Готовый тренажёр для ребёнка по материалам Spotlight 5. В стартовом словаре 36 тематических уроков и 356 слов и фраз. В каждом уроке есть карточки с произношением и примерами, а в тренировке — четыре отдельных навыка.

## С чего начать

1. Для знакомства открой `wordberry-preview.html` двойным щелчком. В нём работают уроки, тренировки и профиль в текущем браузере. Этот файл не подключает облачную регистрацию.
2. Для постоянного использования опубликуй **весь проект** на Netlify по инструкции ниже. Тогда заработают логин, пароль и сохранение прогресса между устройствами.
3. Более удобная инструкция для открытия в браузере — `START_HERE.html`.

## Что уже работает

- Профиль с именем или псевдонимом и значком. Облачный профиль: уникальный логин и пароль от 8 символов; детская почта не нужна.
- Вход в тот же профиль с другого устройства. История привязана к аккаунту, а не к имени как тексту.
- Возврат к следующей карточке незавершённого занятия, в том числе после закрытия страницы.
- Перевод: выбрать значение английского слова.
- Написание: вспомнить и написать английское слово по русскому переводу.
- На слух: услышать слово и написать его, не видя английского текста.
- Предложения: вставить слово или фразу в пропуск по смыслу и переводу.
- Обычная и замедленная озвучка слов и примеров английским голосом устройства.
- Запись своего голоса в карточке и прослушивание для сравнения. Запись временная, на сервер не отправляется, автоматической оценки произношения нет.
- Повтор ошибочной карточки в конце занятия и дальнейшее повторение по расписанию.
- Отдельные показатели по каждому навыку, дневная цель и история за семь дней.
- Добавление своих уроков из домашнего задания. Они тоже сохраняются в облачном профиле.
- Отчёт CSV, читаемый в Excel, и экспорт JSON с прогрессом. Обратная загрузка JSON в этой версии не реализована.
- Восстановление пароля по коду, который приложение показывает один раз при регистрации.
- Несколько детей: отдельный облачный аккаунт с отдельным логином для каждого ребёнка; в ознакомительном режиме — выбор сохранённого локального профиля.

## Два способа сохранения

| Вариант | Где находится прогресс | Другое устройство |
| --- | --- | --- |
| Зарегистрированный профиль на Netlify | На сервере; текущие ответы также временно сохраняются в браузере до отправки | Вход по тому же логину и паролю |
| Ознакомительный профиль | Только в данных текущего браузера | Автоматического переноса нет |

Верхняя строка показывает состояние сохранения. «Прогресс сохранён» означает, что очередь ответов отправлена. «Нет связи · ответы сохранены здесь» — ответы лежат в текущем браузере и ждут синхронизации. Можно нажать на эту строку и повторить отправку. Если истекла сессия, там же можно войти снова.

При очистке данных браузера неотправленные ответы и локальные профили удаляются. Уже отправленный облачный прогресс остаётся в аккаунте. Локальный профиль автоматически не превращается в облачный: для постоянных занятий зарегистрируйся сразу после публикации.

## Размещение на Netlify через GitHub

Это рекомендуемый путь для версии с регистрацией: Netlify установит зависимости, соберёт сайт и развернёт серверную функцию.

### Если текущий deploy упал: scripts/build.mjs не найден

Для уже созданного репозитория `shchnovo/wordberry-english`:

1. Распакуй весь архив проекта. Открой папку, внутри которой рядом лежат `package.json`, `netlify.toml` и папки `scripts`, `src`, `data`, `shared`, `server`, `netlify`.
2. Открой https://github.com/shchnovo/wordberry-english в ветке `main` и нажми **Add file → Upload files**.
3. В проводнике выдели **всё содержимое** распакованной папки, включая вложенные папки, и перетащи его в окно загрузки GitHub. Дождись загрузки всех файлов.
4. Нажми **Commit changes**, сохранив изменения в `main`.
5. Проверь на GitHub пути `scripts/build.mjs`, `src/index.html`, `data/course.json`, `server/handler.mjs` и `netlify/functions/wordbook.mjs`.
6. Открой **тот же проект Netlify** и его раздел **Deploys**. После обновления подключённой ветки Netlify обычно запустит новую сборку автоматически; если запуск не появился, запусти повторную сборку последнего deploy вручную.

Настройки остаются прежними: Base directory — пусто, Build command — `npm run build`, Publish directory — `dist`, Functions directory — `netlify/functions`. Дополнительная папка перед `scripts` и `src` в репозитории не нужна.

Файл `wordbook.mjs`, который ранее оказался в корне репозитория, можно удалить после загрузки полной структуры: рабочая функция находится в `netlify/functions/wordbook.mjs`.

После успешной публикации должны появиться вкладки «Войти» и «Создать профиль». Затем ответь на несколько вопросов, дождись «Прогресс сохранён» и проверь вход с тем же логином на другом устройстве.

### Шаг 1. Распакуй архив

Найди папку, где рядом лежат `package.json`, `package-lock.json`, `netlify.toml`, `README.md` и папки `src`, `shared`, `data`, `server`, `netlify`, `scripts`, `tests`, `dist`.

Загружать нужно содержимое этой папки. Не загружай архив ZIP как один файл в репозиторий.

### Шаг 2. Создай репозиторий на GitHub

1. Открой https://github.com/new и создай репозиторий, например `wordberry-english`.
2. Можно выбрать Private: проект предназначен для вашей семьи.
3. Через **Add file → Upload files** перетащи файлы и папки проекта, сохраняя вложенность, затем нажми **Commit changes**.
4. На первой странице репозитория должны быть видны `package.json` и `netlify.toml`, а в папке `netlify/functions` — файл `wordbook.mjs`.

Перед подключением Netlify открой репозиторий и проверь, что на GitHub появились **все папки проекта**, а не только отдельные файлы:

- `scripts/build.mjs` — команда сборки из `package.json`;
- `src/` — страницы, стили и код интерфейса;
- `data/course.json` — слова и уроки;
- `shared/core.mjs` — правила обучения и прогресса;
- `server/handler.mjs` — регистрация и сохранение;
- `netlify/functions/wordbook.mjs` — серверная функция.

Если Netlify сообщает `Cannot find module '/opt/build/repo/scripts/build.mjs'`, в репозиторий не попала папка `scripts` или нарушена вложенность. Загрузить только `package.json`, `package-lock.json` и `netlify.toml` недостаточно: нужны все перечисленные исходники. Файл `wordbook.mjs` должен находиться именно в `netlify/functions`, а не в корне репозитория.

В репозиторий попадает код приложения. Имена зарегистрированных детей, пароли и учебные результаты туда не записываются.

### Шаг 3. Подключи Netlify

1. Войди на https://app.netlify.com/.
2. Создай проект импортом существующего репозитория: **Add new project / Import an existing project → GitHub**.
3. Выбери `wordberry-english`.
4. Настройки должны подтянуться из `netlify.toml`. Проверь:

| Поле | Значение |
| --- | --- |
| Base directory | Пустое, если файлы лежат в корне репозитория |
| Build command | `npm run build` |
| Publish directory | `dist` |
| Functions directory | `netlify/functions` |
| Node.js | 22, задано в конфигурации |

5. Запусти публикацию и дождись успешного deploy.

Не нужно вручную добавлять ключи стороннего ИИ или подключать отдельную внешнюю базу. Для сохранения приложение использует Netlify Functions и Netlify Blobs с автоматической конфигурацией. Доступность и использование этих возможностей зависят от условий вашего аккаунта Netlify.

### Шаг 4. Убедись, что включилась регистрация

Открой опубликованный адрес в новом браузере или приватном окне. Должны появиться вкладки **«Войти» / «Создать профиль»**.

Если сразу показывается только имя с надписью «Этот профиль … только в текущем браузере», серверная часть недоступна. Проверь успешность deploy, наличие функции `wordbook` в разделе Functions и правильные каталоги. Загрузка одной папки `dist` или одного HTML-файла разворачивает только интерфейс, без этой регистрации.

После первой регистрации появится хранилище `wordberry-v1` в **Data & Storage → Blobs**. Его приложение читает и изменяет только через серверную функцию с проверкой аккаунта.

### Шаг 5. Создай профиль ребёнка

1. Нажми «Создать профиль».
2. Введи имя или псевдоним, логин и пароль от 8 символов.
3. Сохрани код восстановления у взрослого.
4. Открой «Мои уроки» и выбери тот модуль, который сейчас проходите в школе.
5. Начни с 3–5 слов и режима «Все 4 навыка».

Не обязательно начинать со Starter. Например, для темы школьных предметов сразу открывай 1a.

### Шаг 6. Проверь память на своём Netlify

- Ответь на несколько карточек и дождись строки «Прогресс сохранён».
- Закрой страницу. Открой снова: должны сохраниться имя и карточка продолжения.
- На другом устройстве войди с тем же логином и паролем: должен открыться тот же прогресс.
- В карточке проверь обычное и замедленное произношение. Голос и звук зависят от браузера и устройства.

Эти действия подтверждают работу уже опубликованного сайта, включая настоящие сервисы Netlify. До публикации реальные облачные сервисы и озвучку на вашем устройстве проверить нельзя.

### Шаг 7. Добавляй новые домашние задания

«Мои уроки» или «Настройки» → «Добавить свой урок». Формат каждой строки:

```text
apple | яблоко | I eat an apple. | Я ем яблоко.
window | окно | Open the window. | Открой окно.
```

Нужны все четыре поля. В примере английское слово должно быть целиком и в той же форме: для `apple` подходит `an apple`, но `pineapple` не подходит. Примеры составляются взрослым или ребёнком; тренажёр не проверяет их грамматическую правильность автоматически. За один урок — до 60 слов.

### Шаг 8. Обновляй тот же проект

Новые версии кода загружай в тот же GitHub-репозиторий и публикуй в том же проекте Netlify. Данные Blobs привязаны к проекту и сохраняются при новых deploy. Если создать новый отдельный проект, старые аккаунты сами в него не перенесутся.

## Почему «угадала перевод» не равно «выучила»

- **Новое:** ответов ещё нет.
- **В тренировке:** не все навыки подтверждены.
- **Освоено:** есть хотя бы один успешный ответ без подсказки в каждом из четырёх навыков.
- **Закреплено:** есть два успешных ответа подряд в каждом навыке и успешное повторение спустя минимум 20 часов после первой встречи.

Один неверный ответ обнуляет текущую серию только соответствующего навыка. История остальных навыков и общее количество ответов остаются.

Интервалы после верных ответов: 10 минут → 1 день → 3 дня → 7 дней → 14 дней → 30 дней. После ошибки — 5 минут. Это простые правила тренажёра, а не заявление о том, что за эти сроки любое слово гарантированно запомнится.

## Откуда словарь

Тематическая подборка по загруженным файлам Spotlight 5. Учебник содержит 45 страниц PDF и заканчивается модулем 2. Рабочая тетрадь содержит 90 страниц PDF и все 10 модулей. Поэтому Starter и модули 1–2 сверялись по обоим материалам, модули 3–10 — по рабочей тетради.

Словарь — стартовая тематическая подборка, не исчерпывающая оцифровка всех слов учебного года. Учебные предложения и русские переводы составлены для тренажёра. Печатная страница источника указана в каждом уроке.

Исходные PDF, их изображения и аудиозаписи издательства в публичный сайт не включены. Озвучка синтезируется устройством.

## Для разработчика

```sh
npm ci
npm test
npm run build
```

Сборка создаёт `dist` и отдельный `wordberry-preview.html`. Для Netlify важны исходники функции, зависимость `@netlify/blobs`, сборочная конфигурация и каталог `dist`.

- `data/course.json`: стартовый словарь.
- `scripts/make-course.py`: источник словаря для удобного редактирования; Python не нужен для публикации.
- `shared/core.mjs`: общие правила прогресса и проверки ответов.
- `src/app.js`, `src/styles.css`: интерфейс.
- `server/handler.mjs`: регистрация, вход, события, восстановление и удаление.
- `netlify/functions/wordbook.mjs`: функция платформы и ограничение частоты запросов.
- `tests`: проверки словаря, логики обучения, сервера и сценариев интерфейса в DOM-окружении.

Пароли хешируются scrypt с индивидуальной солью. Сессионные токены хранятся в HttpOnly/Secure/SameSite=Strict cookies; на сервере — хеши токенов. Сохранение прогресса использует сильную согласованность, условные записи по ETag и идентификаторы событий для защиты от повторного учёта ответа. Сервер сам проверяет ответ и не принимает готовый клиентский «балл».

Дополнительные переменные окружения, если они нужны:

| Переменная | Назначение |
| --- | --- |
| `REGISTRATION_CODE` | Код приглашения для создания новых профилей; если задан, появится поле ввода кода. Пустое значение позволяет обычную регистрацию. |
| `WORDLAB_STORE` | Имя хранилища; по умолчанию `wordberry-v1`. Для тестовых deploy можно назначить отдельное имя, чтобы не использовать данные семейного сайта. |

Ограничения текущей версии: нет автоматической проверки произношения, нет импорта слов из фото, нет полноценного режима работы без интернета при первом открытии, нет автоматического восстановления JSON-копии. Во время открытого занятия ответы могут ждать отправки в браузере, а озвучка и микрофон зависят от возможностей устройства.

Проверены автоматические сценарии интерфейса и сервера и сборка серверной функции. Визуальная проверка в настоящем браузере и фактическая публикация в аккаунте Netlify в этом окружении не выполнялись.
